# Intro

Hello! I did this as an exercise for K&R. You may ask, "How do I use this". Well heres how it goes:

1) Sample usage if you run through ``cmd.exe`` [RECOMMENDED]
```cmd
a.exe < input.c > output.c
```

2) Sample usage if you run through ``powershell``. Note: This works on powershell 7+. If you don't have it, then just use cmd.

```powershell
.\a.exe < input.c > output.c
```
